# AI-агент для анализа алертов

## Описание проекта

Проект представляет собой интеллектуальную систему на основе GigaChat для анализа технических алертов и обработки пользовательских запросов. Система разделена на два специализированных агента:

1. **Агент анализа алертов** - специализируется на обработке технических алертов, их парсинге, анализе и формировании рекомендаций.
2. **Интерактивный ассистент** - обрабатывает пользовательские запросы, выполняет поиск в документации и координирует взаимодействие с пользователем.

## Архитектура системы

```
src/
├── agents/                 # Специализированные агенты
│   ├── alert_agent.py      # Агент для анализа алертов
│   └── assistant_agent.py  # Интерактивный ассистент
├── tools/                  # Инструменты для агентов
│   ├── alert_tools.py      # Инструменты для анализа алертов
│   ├── api_tools.py        # Инструменты для работы с API
│   └── gigachat_tools.py   # Инструменты для работы с GigaChat
├── alert_processing/       # Модули обработки алертов
│   └── alert_parser.py     # Парсер алертов
├── core/                   # Ядро системы
│   └── prompts.py          # Промпты для моделей
├── integrations/           # Интеграции с внешними системами
└── cli.py                  # Интерфейс командной строки
```

## Функциональность

### Агент анализа алертов

- Парсинг и структурирование алертов
- Анализ причин возникновения проблем
- Поиск решений и формирование рекомендаций
- Оценка критичности проблем

### Интерактивный ассистент

- Обработка пользовательских запросов
- Поиск информации в документации
- Проверка статуса API и токенов
- Перенаправление запросов по анализу алертов специализированному агенту

## Установка и настройка

### Требования

- Python 3.9+
- Учетные данные для доступа к API GigaChat

### Установка

1. Клонировать репозиторий:
```bash
git clone <repository-url>
cd AI-agent
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Создать файл .env с учетными данными:
```
GIGACHAT_CREDENTIALS=your_credentials
GIGACHAT_SCOPE=your_scope
GIGACHAT_VERIFY_SSL_CERTS=False
```

## Использование

Запустить основной скрипт:
```bash
python main.py
```

### Доступные команды:

- `файл` или `анализ файла алерта` - выбор файла с алертом для анализа
- `последний алерт` - информация о последнем проанализированном алерте
- `повторный анализ` - повторный анализ последнего алерта
- `токены` или `проверить токены` - проверка статуса токенов GigaChat
- `exit` - выход из программы

## Разработка

### Структура проекта

- `main.py` - точка входа в приложение
- `src/agents/` - специализированные агенты для разных задач
- `src/tools/` - инструменты для агентов
- `config/` - конфигурационные файлы и настройки
- `tests/` - тесты
- `data/` - данные для работы системы
